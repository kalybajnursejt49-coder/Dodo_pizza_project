Tools and Technologies

The website was created using pure HTML5, without CSS or JavaScript. Styling will be added during the next stage of the project.

  • Code editor: VS Code
  • Version control system: Git and GitHub
  • Markup validation: W3C Validator

Workflow

Nurseit wrote the code, Alfarabi collected and added the photos, and Damir collected information about Dodo Pizza.

The project took one and a half months.

Use of AI

AI was used to understand HTML tags and how they work, as well as to find issues that were forgotten or implemented incorrectly, such as unclosed tags and duplicate IDs. All text, photos, and final page content were created by the project team.
